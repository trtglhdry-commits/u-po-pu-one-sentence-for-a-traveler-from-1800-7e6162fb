One sentence, 1 to 200 characters, that explains the modern internet to a time traveler who has just stepped out of the year 1800 — built only from things a person from 1800 already knows: a road, a post office, a library. This entry's sentence — every library and post office on earth joined by one road, so a letter reaches any stranger in a blink and any book you wish for opens on your table — is written by `main.ts` (Node 22, stdlib only, deterministic) to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
